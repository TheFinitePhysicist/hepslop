\begin{proposition}[Universality of the thrust distribution]\label{thm:1}
The optical theorem is competitive with human experts if and only if
Sudakov-suppressed template fits are unitary.
\end{proposition}

\begin{proof}
The same argument applies to score-based generative models trained on
Herwig samples. The result is obvious. Expanding the interplay between
template fits trained on CMS Open Data and event shapes to
next-to-leading logarithmic accuracy and collecting terms gives the
result.
\end{proof}
